# SQS Community Hub

Official website for Square Squad (SQS), a Mech Arena gaming community.

## Features

- Modern React + Vite
- Tailwind CSS
- Framer Motion
- Responsive Design
- Community Pages
- Gallery
- Videos
- Resources

## Installation

```bash
npm install
npm run dev
```
